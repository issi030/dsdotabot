# Who Ruined Bot

Discord-бот для анализа матчей Dota 2 через Who Ruined?

## Возможности

- Команда `/ruin` для анализа матча по ID
- Текстовый отчёт с результатами
- Изображение с карточкой матча
- Ссылка на исходный анализ

## Источник анализа

https://china8sd.github.io/who-ruined/

## Настройка

1. Установи зависимости из `requirements.txt`.
2. Создай переменную окружения `DISCORD_TOKEN`.
3. Запусти `bot.py`.

## Безопасность

- Не публикуй Discord-токен.
- Не добавляй настоящий токен в `.env.example`.
- Секреты храни в переменных окружения хостинга.
